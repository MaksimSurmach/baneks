# Quiet Archive implementation

The selected reference and full handoff were read before implementation. Source art is the supplied standalone `hero-wide.webp`, not a UI screenshot. Fonts are self-hosted Literata and Golos Text from Fontsource (Cyrillic + Latin); no external font requests. Palette comes from DESIGN_HANDOFF.

The current Linear scope and user request supersede the older handoff's SSR, Worker, backend, search and Atlas recommendations. This is a static browser-only catalogue. Search is visibly disabled; Atlas is a lazy loaded placeholder. No ratings, titles, votes or tags are invented at runtime.

Intentional refinements: actual catalogue rating/ID sorting replaces mockup relevance; a random action and honest unavailable-search note occupy the metadata area; topics show six options with disclosure for the rest; native modal filter sheet below 900px; list snippets only shorten bodies over 1000 characters, detail preserves the complete text. Imported scores are textual catalogue ratings, and AI-proposed taxonomy is labelled. Body typography uses 18px/1.65 for readable long dialogues rather than the mockup's compressed line spacing.

Browser screenshots at 1440, 768 and 390 are generated by `tests/e2e/visual.spec.ts`. They use **test fixtures through Playwright interception**, not verified production content; production currently rejects anonymous reads. Compare composition with `references/catalog-selected-reference.png`; live content screenshots remain a release gate after Neon access is repaired.
